# Система корпоративных закупок

Данный репозиторий содержит в себе проект на Java, реализующий базовую систему
создания и отслеживания корпоративных закупок. Проект поделён на 4 части:

- Консольное приложение,
- Desktop-приложение на JavaFX,
- Web-приложение с REST API,
- Мобильное приложение для Android.

## Требования для запуска

Проект построен на последней стабильной версии Java (LTS) - 25. Помимо этого,
используется система сборки Gradle последней версии. Для сборки единого
JAR-файла используется плагин [Shadow Gradle](https://gradleup.com/shadow/).

```bash
./gradlew shadowJar
```

## Проверки экспорта CSV

Экспорт доступен менеджеру в пункте **6**. Укажите папку; допускаются пути
в кавычках и `~/` для домашней папки. `0` отменяет действие. Пустые пути и пути
с управляющими символами отклоняются. При ошибке доступа или записи можно
повторить ввод. Каждая выгрузка создаётся в новой подпапке без перезаписи старой.

CSV сохраняется в UTF-8 с запятой в качестве разделителя. Проверяются непустые
уникальные заголовки, количество столбцов в строках, корректность Unicode,
недопустимые управляющие символы и нечисловые значения NaN/Infinity.
Если данные некорректны, незавершённая выгрузка удаляется.

Для защиты от CSV-инъекций текст с префиксами формул (`=`, `+`, `-`, `@`),
в том числе после пробелов и невидимых символов, получает начальный апостроф.
Это касается и текста с начальной табуляцией или переносом строки.
Апостроф добавляется только в экспортируемый текст; данные в базе не изменяются.
Числа сохраняются числами, запятые, кавычки и переносы строк экранируются.
